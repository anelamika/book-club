# Книжный клуб — выбор книги

Веб-страница для честного случайного выбора книги на встречу книжного клуба.

**Открыть онлайн:** [https://anelamika.github.io/book-club/](https://anelamika.github.io/book-club/)

## Как пользоваться

1. **Загрузить** — таблица в формате CSV, XLS или XLSX с колонками: №, Название, Автор, Жанр, Сложность, Кто добавил книгу (имя).
2. **Выравнять** — книги группируются по людям; в коротких списках названия дублируются, чтобы у всех было одинаковое число позиций.
3. **Перемешать** — все позиции собираются в один список и перемешиваются.
4. **Выбрать случайную книгу** — книга выбирается из итогового списка (с обратным отсчётом). Можно запускать снова.

## Локальный запуск

Откройте `index.html` в браузере. Хостинг для этого не нужен — достаточно файлов `index.html` и папки `vendor/`.

Пример таблицы для проверки: `sample-books.csv`.
